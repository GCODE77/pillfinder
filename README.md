# 필파인더 (Pill Finder)

© GLORY KIM

카메라로 약을 비추면 **모양 · 색 · 장단축 비율 · 각인 · 크기**로 무슨 약인지 찾아 주고,
약 이름으로 검색하면 **효능 · 용법 · 주의사항 · 부작용 · 보관법**까지 보여 주는 웹앱(PWA)입니다.
갤럭시(크롬·삼성 인터넷)와 PC 브라우저에서 똑같이 쓰고, 홈 화면에 추가하면 앱처럼 쓸 수 있습니다.

> 식별 **보조** 도구입니다. 모양이 같은 다른 약이 있을 수 있으니 복용 전 약 봉투·포장의 이름을 확인하세요.

## 기능

| 기능 | 설명 |
|---|---|
| **실시간 윤곽** | 카메라를 비추는 동안 약 테두리를 금색으로 따라 그리고, 모양·색·비율을 화면에 바로 표시 |
| **자동 촬영** | 윤곽이 0.9초 동안 멈춰 있으면 저절로 찍어서 찾기(끄기 가능) |
| **거리와 무관한 식별** | 사진 속 크기는 거리마다 달라서 쓰지 않고, 윤곽을 단위원으로 정규화한 **모양 고조파**, **장단축 비율**, 색, 각인으로 비교 |
| **동전 기준 실제 크기** | 100원(설정에서 10·50·500원) 동전을 옆에 두면 동전 지름으로 약의 실제 mm 크기를 재서 비교 |
| **각인 판독** | 약을 장축 방향으로 눕혀 잘라내고, 음각(새김)·인쇄 각인을 세 가지 방식으로 강조해 OCR(기기 안에서, 오프라인). 둥근 약은 글자 줄 방향을 찾아 세움 |
| **AI 판독(선택)** | 본인 Claude API 키를 넣으면 AI가 각인·색·모양을 읽어 함께 반영(음각 각인에 강함, 호출마다 요금) |
| **앞·뒷면** | 뒷면도 찍으면 두 면의 각인을 합쳐 찾음 |
| **바로 고치기** | 결과에서 모양·색·각인·크기를 고치면 즉시 다시 순위를 매김 |
| **이름 검색** | 이름·초성(ㅌㅇㄹㄴ)·업체·영문명·각인으로 검색 |
| **모양으로 찾기** | 각인·모양·색(비슷한 색 포함)을 골라 찾기 |
| **상세** | 실물 사진, 모양·색·각인·크기, 효능·용법·주의·상호작용·부작용·보관, 의약품안전나라·약학정보원 원문 링크 |
| **내 약 · 기록** | 자주 먹는 약 저장, 최근 찍어서 찾은 기록(기기 안에만 저장) |
| **PC** | 사진 불러오기, 끌어다 놓기, 붙여넣기(Ctrl+V), 약 상세 링크 공유 |

## 처음 설정 (한 번만)

1. **공공데이터포털 인증키** — [data.go.kr](https://www.data.go.kr) 회원가입 후 위 세 API를 각각 "활용신청"(개발계정은 자동 승인, 반영까지 1시간 정도).
   마이페이지의 **일반 인증키(Decoding)** 를 복사합니다.
2. **GitHub 저장소** — 새 저장소(예: `pillfinder`)를 만들고 이 폴더를 올립니다.
   - Settings → Secrets and variables → Actions → `SERVICE_KEY` 에 인증키
   - Settings → Pages → Source: **GitHub Actions**
3. 올리면 Actions가 식약처 데이터를 받아(20~40분) `https://<아이디>.github.io/pillfinder/` 로 배포합니다. 이후 **매주 월요일 새벽** 자동 갱신.
4. **갤럭시** — 크롬 또는 삼성 인터넷에서 주소를 열고 메뉴 → **홈 화면에 추가**(앱 설치). 카메라 권한 허용.

인증키는 GitHub Secret에만 두고, 앱(브라우저)에는 실리지 않습니다.

## 개발

```bash
python -m http.server 8771
```
- `http://localhost:8771/index.html?demo` — 가짜 데모 데이터(`tests/demo/`, `node tests/make-demo.js`로 생성)로 화면 확인
- 실제 데이터: `SERVICE_KEY=<키> node scripts/build-data.mjs` (허가 상세 생략은 `PERMIT=0`, 일부만 `LIMIT=3`)
- 테스트: `npm test` (합성 사진 30장 모양·색·비율·동전 크기 + 매칭 11건)

카메라는 `https` 또는 `localhost`에서만 켜집니다.
